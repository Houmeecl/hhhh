Cómo se garantiza el aislamiento

No es un filtro de pantalla: cada sesión lleva su panel y su entidad grabados en el token, y el servidor filtra cada consulta por esa entidad. Un puerto no puede pedir datos de otro punto ni construyendo la URL a mano. Cada panel tiene además su color de identidad, para que el operador siempre sepa dónde está.

Panel de Puerto (azul): tránsitos del propio punto, con estados y cadena de custodia.

2. Así se ve cada rol

Agencia (ámbar): expedientes asignados y captura documental.

Trazador (rojo): cruces de un RUT autorizado — sesiones, quién le emite, a quién le emite.

Proveedor (turquesa): lotes pendientes de firma, con formulario en línea.

3. Cómo se incorpora un actor (desde tu admin)

1
Se crea la entidad en Accesos externos (puerto, mandante, agencia, proveedor o trazador), con sus permisos: punto del corredor, RUT autorizados, lotes asignados.
2
Se le crea el acceso web con un clic: el sistema envía la activación y fuerza el cambio de contraseña en el primer ingreso. Para roles que firman, se puede exigir llave física FIDO2.
3
El actor opera solo. Todo lo que hace queda en el log de actividad y, cuando corresponde, sellado en la cadena del lote.

4. Para integraciones: API y webhooks

El mandante que prefiere integrar sus sistemas usa la API con clave (encabezado X-Api-Key) para los mismos datos de su panel — proveedores, Alcance 3, CBAM — y puede suscribir un webhook para recibir eventos en su propio sistema.

¿Qué le cuesta al actor externo entrar?
Nada de infraestructura: navegador y su credencial. Los paneles funcionan en escritorio, tablet y teléfono.
¿Puede un actor negarse a usar otra plataforma más?
Es la objeción clásica, y la respuesta es el diseño: cada panel hace UNA cosa (firmar, consultar, capturar) y se aprende en minutos — no es "otro sistema", es un formulario con respaldo.
